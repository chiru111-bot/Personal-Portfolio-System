# Personal Portfolio Management System

**A Full-Stack Web Application Using MERN Stack**

## 1. Project Overview

The Personal Portfolio Management System is a full-stack web application developed to help users create, organize and manage their professional portfolio information.

The application provides a centralized platform to manage educational qualifications, technical skills, personal projects and professional experience.

It uses the MERN Stack to provide an organized, interactive and user-friendly portfolio management experience.

## 2. Objectives

- Develop a dynamic portfolio management application.
- Organize personal and professional information.
- Manage educational qualifications.
- Showcase technical skills and projects.
- Maintain professional experience details.
- Implement CRUD operations.
- Provide an interactive user interface.

## 3. Technologies Used

| Technology | Purpose |
|---|---|
| React.js | Frontend development |
| Node.js | Backend runtime |
| Express.js | REST API development |
| MongoDB | Database management |
| Mongoose | Database operations |
| Axios | HTTP requests |
| JavaScript | Application logic |
| CSS | Interface styling |
| Postman | API testing |

## 4. Main Features

- Education details management.
- Technical skills management.
- Project information management.
- Professional experience management.
- Create, Read, Update and Delete operations.
- RESTful API integration.
- Tab-based user interface.
- Modular application structure.
- API testing using Postman.

## 5. System Architecture

The application follows a client-server architecture.

**Frontend:** React.js provides an interactive interface for managing portfolio information.

**Backend:** Node.js and Express.js handle requests and process application logic.

**Database:** MongoDB stores portfolio information.

**API Testing:** Postman is used to test backend API endpoints.

## 8. Installation and Setup

### Prerequisites

- Node.js
- npm
- MongoDB
- Visual Studio Code
- Postman (for API testing)

### Clone Repository

```bash
git clone https://github.com/chiru111-bot/Personal-Portfolio-System.git

cd Personal-Portfolio-System
```

### Install Dependencies

```bash
npm install
```

### Database Configuration

Configure the MongoDB connection string using the environment variables required by the application.

### Run Application

Use the development scripts specified in the respective package.json files to start the backend and frontend.
